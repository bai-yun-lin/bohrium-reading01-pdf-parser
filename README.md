# 科研 PDF 解析 · 阅读01

以原始 PDF 为输入，导出可编辑 Markdown、结构化段落、表格、公式候选、页面预览与证据清单。每个对象保留物理页码和边界框，方便审阅者直接回到论文。安装与正式案例调用见 [SKILL.md](SKILL.md)。

## 快速复现

本地 Python 3.9+ 与 PyMuPDF 可运行完整合成自测。若自行准备环境，安装 `pymupdf`；赛事环境优先使用预装工具。OCR 使用现有 Tesseract 语言数据，无语言包时输出缺口和待核对原页。仅有 Poppler 时，正式解析脚本可使用文字层、词坐标、对齐表格和页面渲染，自测生成 PDF 需要 PyMuPDF。

```sh
python scripts/selftest.py demo
```

打开 `demo/output/previews/d1-p1.png`，对照 `demo/output/documents/d1.md`。JSON 中 `pages[].elements` 保留全部底层证据，`reading_order` 给出正文和结构对象的顺序，`margin_ids` 给出单独保存的页边信息。扩展字段和教材中的合成输入都可阅读和修改。

若环境中有 Pillow，可运行 `python scripts/inspect_page.py demo/output d1 1 demo/page1-check.png`。左侧为源页渲染，右侧标出阅读序号、图像与逐格边界。按需对困难页面生成，所有图像留在运行输出目录。本地完整验证使用 PyMuPDF 2.1、英语 tessdata_fast 和 Poppler 25.02 的独立回退路径。

## 已执行的对照

| 材料 | 检查与观测 |
|---|---|
| 三页合成 PDF | 在相同 PDF 字节上比较内容流顺序与按版面排序。12 个已知标记，内容流存在 7 个逆序对，按版面排序为 0。断言检查跨栏标题前后顺序、重复页眉、合并表头、两项周期值、无框表及公式中的 π 和 √。 |
| 同一文件的扫描页 | 该页只嵌入像素。本地英语 OCR 恢复了 `Standard reading 12.0 seconds`。没有 OCR 时，同一页保留预览并记录无法转录。 |
| 公开论文的真实表格 | 对 Huang 等人的 *Densely Connected Convolutional Networks*（arXiv v5）运行解析。物理第 5 页 Table 2 只有部分列间格线，初始格线提取把 8 个字段挤成 5 组。按表头和重复数据行校正后得到 8 列；对照原页，DenseNet-BC、k=24、深度 250 行的 C10+ 为 3.62、C100+ 为 17.60。原文数字为错误率百分比。 |

上述合成调序指标是与相同内容流的技术对照。真实论文验证只覆盖描述的页与字段。三个赛事案例与基础 Agent 的分数由赛事方测定。公开论文仅作为外部验证材料，仓库仅包含代码与合成样例生成器。[验证用论文](https://arxiv.org/abs/1608.06993)

## 常见边界

Word 位置不能单独确定科学含义。无边框跨页表、图片内公式、旋转边注和横跨多栏的矢量图应结合源页核查。双栏切分先寻找上下有共同覆盖的栏间空白，再按跨栏元素分带；短页、边注与复杂广告版式可能需要调整顺序。OCR、标题识别、相邻图题和跨页连续性均保留待复核标识。维护或修改算法后，先复跑合成用例，再选一篇同版式原文逐项验证。
